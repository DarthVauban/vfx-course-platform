# Перевірені офіційні джерела

Дата доступу до всіх URL у цьому файлі: **2026-07-27**.

Технічна база курсу: **Unreal Engine 5.8**. Станом на дату доступу UE 5.8 є публічним релізом, а основний портал Epic показує документацію Unreal Engine 5.8.

У каталозі нижче використано лише першоджерела:

- Epic Games / Unreal Engine Documentation та Unreal Engine API;
- Adobe Photoshop Help;
- Adobe Substance 3D Designer Documentation на Experience League;
- Blender Reference Manual.

Сторонні tutorials, форуми, wiki, агрегатори й перекази документації не є нормативними джерелами цього курсу. Посилання Adobe та Blender із позначкою `rolling` можуть змінюватися без фіксації версії, тому перед записом або великим оновленням уроку їх потрібно перевіряти повторно.

## Правило цитування в уроках

Для твердження, що залежить від версії Unreal Engine, урок має:

1. послатися на відповідний `ID` із цього каталогу;
2. указати `Unreal Engine 5.8`;
3. не переносити точні menu paths, node names або defaults зі старішої документації без перевірки;
4. додати позначку **«Потребує ручної перевірки в Unreal Engine 5.8.»**, якщо тема є в реєстрі `MC-*`;
5. після ручної перевірки записати build UE 5.8.x, дату, test asset/map і фактичний результат.
