# Reference and source compliance

## Reference

- [ ] Source name, organization/author, direct URL і access date записані.
- [ ] Для video вказано timestamp.
- [ ] Аналізуємо principle: silhouette, value, timing, motion, readability.
- [ ] Proprietary textures, meshes, materials, flipbooks або project files не вилучалися.
- [ ] Independent variant має іншу constraint, shape hierarchy і timing.
- [ ] Portfolio caption не створює враження авторства reference design.

## Technical claim

- [ ] UE claim звірено з official UE 5.8 docs або встановленим UE 5.8.x.
- [ ] Exact node/module/panel name не вигадано.
- [ ] Experimental/Beta status перевірено.
- [ ] Version-sensitive UI не описано як гарантовано незмінний.
- [ ] Performance number має test contract.
- [ ] Employer requirement походить із current official careers page або не подається як факт.

## Якщо не підтверджено

Використайте точний маркер:

`Потребує ручної перевірки в Unreal Engine 5.8.`

- [ ] Маркер стоїть біля конкретного claim, а не прихований у загальному disclaimer.
- [ ] У `SOURCES.md` додано, що саме треба перевірити.
- [ ] Непідтверджена feature не є mandatory dependency.
