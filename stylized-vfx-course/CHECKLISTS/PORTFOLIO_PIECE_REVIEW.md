# Portfolio piece review

## Creative brief

- [ ] Gameplay action, audience і camera описано.
- [ ] Element/theme має власну shape і motion language.
- [ ] Primary visual goal сформульовано одним реченням.
- [ ] Constraints і non-goals зафіксовано.
- [ ] Reference analysis цитує джерела й не копіює proprietary assets.

## Production

- [ ] Thumbnail/value/timing plan існує до polishing.
- [ ] Layer list пояснює роль кожного Emitter/material/mesh.
- [ ] Source textures і meshes власні або мають задокументоване право використання.
- [ ] Naming, folders, Material Instances і reusable modules охайні.
- [ ] Gameplay integration працює, а не імітується лише в Sequencer.
- [ ] Sequencer використано тільки для presentation capture.

## Art direction

- [ ] Primary shape читається на thumbnail.
- [ ] Negative space навмисний.
- [ ] Value hierarchy працює в grayscale.
- [ ] Dominant/accent colors мають різні roles.
- [ ] Anticipation/contact/dissipation відповідають gameplay.
- [ ] Secondary motion staggered, а не одночасний.
- [ ] Effect читається на світлому, середньому й темному фоні.
- [ ] Camera dependence перевірено.

## Technical

- [ ] Material graph review пройдено.
- [ ] Niagara System review пройдено.
- [ ] Performance pass пройдено.
- [ ] User Parameters і renderer bindings документовано.
- [ ] Bounds/culling/lifecycle правильні.
- [ ] High/Medium/Low variants існують і зберігають ігрову підказку.

## Presentation package

- [ ] 5–12 s beauty loop або повний ability capture.
- [ ] Gameplay camera capture.
- [ ] Neutral-background capture.
- [ ] Slow-motion breakdown позначено як slow motion.
- [ ] Layer-by-layer breakdown.
- [ ] Material graph overview + один детальний branch.
- [ ] Niagara stack/emitter map.
- [ ] Texture sheet і mesh wireframe/UV.
- [ ] H/M/L comparison.
- [ ] Performance evidence із test contract.
- [ ] Короткий case study: problem, decisions, iteration, result.

## Definition of Done

- [ ] Робота набрала не менше 80/100 за project rubric.
- [ ] Жодна critical category не нижче 60%.
- [ ] Немає known blocker, crash, immortal system або неправдивої ігрової підказки.
- [ ] Автор може пояснити кожен layer без course solution.
- [ ] Усе, що потребує target-hardware confirmation, чесно позначено.
